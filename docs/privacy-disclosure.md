# 隐私披露与 Limited Use

## 数据处理范围

中文同传 Dubbing 只在用户主动点击启动后捕获当前标签页音频。音频用于实时翻译、中文字幕生成和中文配音播放。

音频会从扩展发送到自有后端，再由后端代理到阿里百炼实时翻译服务。客户端不保存阿里 API Key，也不会把云服务密钥写入扩展。

开启“极速预听”时，扩展会使用浏览器或系统提供的本地中文语音播放已经返回的中文字幕文本，用于降低可听中文首声延迟。该预听路径不新增原始音频上传，不新增声纹处理，也不替代阿里原声音色中文译声。

默认不保存原始音频，不保存声纹，不持久保存可还原用户声音身份的数据。声音复刻只用于当前实时同传会话中的中文配音效果。

## 保存的数据

服务端只保留完成产品功能所需的最小数据：

- 账号和订阅状态。
- 翻译分钟数、额度扣减和并发限制。
- 支付订单状态和必要对账记录。
- 延迟诊断指标，例如首字、首音、播放开始时间的聚合统计。
- 错误码和必要故障诊断日志。

## Limited Use

Limited Use: 用户数据只用于实时翻译、中文配音、字幕展示、计费、额度管理、并发限制、安全风控和故障诊断。不会出售用户数据，不会把音频、声纹或观看内容用于广告定向，也不会用于与本扩展核心功能无关的目的。

## 用户控制

- 音频捕获必须由用户点击启动触发。
- 用户点击停止、关闭标签页、刷新页面或页面跳转时，会停止同传并断开音频流。
- 用户可以在 Chrome 扩展管理页关闭站点访问权限或卸载扩展。

## 第三方处理方

实时翻译和配音链路会使用阿里百炼实时翻译服务。上线前，官网隐私政策必须列明第三方处理方、处理目的、数据类型、保留周期和用户联系渠道。
