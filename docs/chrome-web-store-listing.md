# 中文同传 Dubbing - Chrome Web Store Listing

## 单句简介

用户点击启动后，实时捕获当前标签页音频，把英语视频转换成中文字幕和中文配音。

## 详细描述

中文同传 Dubbing 是面向英语视频学习、跨语言观看和内容理解的 Chrome 扩展。用户在当前播放页主动点击启动后，扩展会捕获当前标签页音频，实时生成中文字幕，并播放中文配音。

第一版覆盖 Chrome 浏览器内的网页播放器，包括 YouTube、优酷、B站、普通 HTML5 video，以及 Chrome 能直接播放的本地 mp4/webm 视频文件。mkv/avi、VLC、IINA、QuickTime 等独立本地播放器或非 Chrome 可播格式不在第一版范围内。

核心能力：

- 用户点击启动后捕获当前标签页音频。
- 英语音频实时转中文字幕。
- 中文配音与原声音量可分别调节。
- 字幕可在普通页面和播放器全屏状态显示。
- 本地文件页需要用户在 Chrome 扩展详情中允许 file:// 访问后才能使用。

本扩展不会在后台自动监听浏览器音频。停止按钮、页面刷新、标签页关闭或跳转时，会立即停止同传会话。

## 审核说明

本扩展需要访问网页播放器和 Chrome 可播放本地视频页面，是为了在用户主动启动后显示字幕层、捕获当前标签页音频，并播放中文译声。音频不会在用户未点击启动时被捕获。
